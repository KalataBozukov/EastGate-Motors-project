# EastGate-Motors-project
Car import website built with HTML, CSS, and JavaScript, featuring product pages, an order form, and dynamic customer reviews
## Features

- Home page with five available vehicles
- Separate details page for each vehicle
- Prices displayed in euros
- Order form with a confirmation message
- Review form that adds new customer reviews
- Responsive layout for desktop and mobile devices

## Vehicles

- Mercedes-Benz E 220 d
- BMW 530i xDrive
- Audi A6 45 TFSI quattro
- Genesis G80 2.5T AWD
- Hyundai Palisade 2.2 CRDi 4WD

## Technologies

- HTML5
- CSS3
- JavaScript

## Run locally

Download or clone the repository and open `index.html` in a web browser. No installation or additional software is required.
